Описание проекта

Данный проект представляет собой простой веб-сервис для управления задачами (планировщик задач).

Приложение позволяет:

создавать задачи;
просматривать список задач;
редактировать задачи;
удалять задачи;
отмечать задачи как выполненные;
автоматически рассчитывать следующую дату выполнения для периодических задач.

Все задачи хранятся в базе данных SQLite.
Серверная часть написана на языке Go, а взаимодействие с приложением происходит через HTTP API и веб-интерфейс.

Задания повышенной трудности не выполнялись.

Запуск проекта локально
1. Требования

Перед запуском убедитесь, что установлены:
Go 1.20+

2. Клонирование репозитория
git clone https://github.com/GeaRvant/go_final_project.git
cd go_final_project
3. Установка зависимостей
go mod download
4. Запуск сервера
go run main.go

После запуска сервер стартует на порту:
http://localhost:7540

Откройте этот адрес в браузере.
При первом запуске автоматически создаётся база данных:
scheduler.db

Запуск тестов
Для запуска автотестов выполните команду:
go test ./tests
Перед запуском тестов необходимо проверить параметры в файле:
tests/settings.go
Используемые параметры:

var Port = 7540
var DBFile = "../scheduler.db"
var FullNextDate = false 
var Search = false 
var Token = ``

После этого тесты можно запускать стандартной командой Go.

Сборка и запуск проекта через Docker не реализованы.
